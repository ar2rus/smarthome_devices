# Настройка Wi‑Fi SmarthomeBridge

Домашние SSID, пароль, статический адрес и часовой пояс больше не задаются в исходном коде. Они сохраняются в эмулируемой EEPROM ESP8266 вместе с версией формата и CRC32. Пароль не возвращается через HTTP API.

## Первый запуск

Если корректной сохранённой конфигурации нет, ESP создаёт защищённую точку:

- SSID: `SmarthomeBridge-XXXXXX`, где суффикс — chip ID;
- пароль: `12345678`;
- адрес страницы: `http://192.168.4.1/config`.

Wildcard DNS и ответы на распространённые captive-portal URL ведут на `/config`. Если LittleFS отсутствует или повреждён, используется минимальная страница, встроенная в прошивку.

Страница в светлом стиле показывает режим сети, параметры AP, адрес клиента и текущее время устройства. Она позволяет выбрать DHCP или задать IP, gateway, mask и DNS, а также выбрать часовой пояс для NTP. После сохранения ESP перезагружается. Пустое поле пароля сохраняет прежний пароль только для того же SSID. При смене SSID пустое поле означает открытую сеть; для явного удаления старого пароля есть отдельный флажок.

## Восстановление связи

С сохранёнными параметрами мост работает в STA. Если подключение не установилось за 60 секунд, он включает AP. При сохранённой конфигурации AP остаётся доступным 15 минут, затем мост снова пробует STA. После очередной неудачи цикл повторяется. Без сохранённой конфигурации AP работает постоянно.

В обычной сети `/config` доступен по адресу моста. Кнопка перехода в AP включает его без удаления настроек. Переход и сохранение блокируются во время прошивки, активной команды или пока очереди не пусты.

В AP закрывается multicast, новые CLUNET-команды и сетевой запуск прошивки получают отказ, SSE и файловый редактор не принимают новые подключения. UART с приложением AVR продолжает обслуживаться. Диагностика `/bridge/status` показывает `wifiMode`, факт наличия настроек, адреса STA/AP и имя AP.

## Обновление существующего моста

После установки этой версии прежние параметры из исходника автоматически не переносятся. При первом запуске мост откроет AP, где сеть нужно сохранить заново. Резервная встроенная страница позволяет сначала обновить только прошивку ESP; полный `config.html` появится после обновления LittleFS.

Загрузчик AVR и приложение AVR для этой функции не меняются. Сетевые настройки ESP также не входят в HEX AVR.

Старый пароль домашней сети присутствовал в истории Git до удаления из исходника. Если репозиторий когда-либо был доступен посторонним, пароль следует заменить на роутере: удаление строки в новом коммите не удаляет её из старых коммитов.

## Проверка

`tests/network_config_regression.py` проверяет CRC, повреждение данных, DHCP/static IP, часовые пояса, завершение строк и отсутствие домашнего пароля/выдачи сохранённого пароля в текущем исходнике. Полная сборка проверяется с ESP8266 Core 3.1.2 и отдельно без необязательного `SPIFFSEditor`.
